## Conscientização de Segurança

- **Conscientização de Segurança (Security Awareness):** Treinamento e comunicação que ajudam os usuários a reconhecer ameaças e seguir um comportamento seguro.
- As pessoas costumam ser alvo porque os atacantes sabem que erros humanos podem contornar os controles técnicos.

## Tópicos Comuns de Conscientização

- Phishing
- Segurança de senhas
- Uso de MFA
- Manuseio de dados
- Navegação segura
- Mídia removível
- Segurança física
- Segurança no trabalho remoto
- Reporte de incidentes
- Práticas de mesa limpa (clean desk)
- Uso aceitável

## Engenharia Social

- **Engenharia Social:** Manipular pessoas para que forneçam acesso, informações, dinheiro ou realizem uma ação.

Sinais de alerta:
- Pressão urgente
- Pedido de sigilo
- Anexo inesperado
- Link suspeito
- Endereço de remetente incomum
- Pedido de senha ou código de MFA
- Pedido de vale-presente ou pagamento
- Personificação de executivo, fornecedor ou suporte de TI

## Defesa contra Phishing

Os usuários devem:
- Verificar o endereço do remetente
- Ter cuidado com anexos
- Passar o mouse sobre os links quando possível
- Ficar atentos a erros de ortografia ou truques de domínio
- Evitar inserir credenciais a partir de links inesperados
- Reportar mensagens suspeitas

## Conscientização para Trabalho Remoto

Riscos do trabalho remoto incluem:
- Wi-Fi público
- Dispositivos compartilhados
- Shoulder surfing (espiar por cima do ombro)
- Notebooks perdidos ou roubados
- Segurança fraca do roteador doméstico
- Armazenamento em nuvem não aprovado

Boas práticas:
- Usar VPN quando exigido
- Bloquear a tela
- Usar MFA
- Manter os dispositivos atualizados
- Proteger os dados da empresa
- Reportar dispositivos perdidos rapidamente

## Reporte

Os usuários devem saber como reportar:
- E-mail suspeito
- Dispositivo perdido
- Suspeita de comprometimento de credencial
- Comportamento incomum do sistema
- Exposição acidental de dados

## Principais Conclusões

- A conscientização ajuda os usuários a reconhecer e reportar ameaças precocemente.
- A cultura de segurança melhora quando o reporte é simples e incentivado.
